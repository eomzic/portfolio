# Portfolio - Eom Yunsik

개인 포트폴리오 웹사이트입니다.

## 📁 프로젝트 구조

```
portfolio/
├── index.html      # HTML 마크업
├── styles.css      # 커스텀 CSS 스타일
├── script.js       # JavaScript 로직
└── README.md       # 프로젝트 문서
```

## 🛠 기술 스택

- **마크업**: HTML5 시맨틱 마크업
- **스타일**: Tailwind CSS + 커스텀 CSS
- **동작**: Vanilla JavaScript (ES6+)
- **차트**: Chart.js
- **아이콘**: Font Awesome 6.4.0
- **폰트**: Noto Sans KR

## 📋 주요 섹션

- **About**: 프로필 및 자기소개
- **Skills**: 기술 스택 (필터링 기능)
- **Experience**: 경력사항 (4년 3개월)
- **Projects**: 대표 프로젝트
- **Strengths**: 강점 및 교육 정보

## 🚀 사용 방법

1. 브라우저에서 `index.html` 파일을 실행하면 됩니다.
2. 네비게이션 메뉴로 각 섹션을 이동할 수 있습니다.
3. Skills 섹션에서 카테고리별 필터링이 가능합니다.

## ✨ 특징

- 반응형 웹 디자인 (모바일/태블릿/데스크탑)
- 부드러운 스크롤 네비게이션
- 동적 스킬 필터링
- Chart.js를 활용한 역량 시각화
- WAI-ARIA 웹 접근성 준수
